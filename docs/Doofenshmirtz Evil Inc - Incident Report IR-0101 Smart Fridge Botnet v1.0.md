# Doofenshmirtz Evil Incorporated
## Incident Report IR-0101 Smart Fridge Botnet — Version 1.0

## 1. Summary

The break room smart fridge joined a botnet and ordered 300 jars of pickles to the lobby. The pickles were donated to the minion cafeteria.

## 2. Timeline

- Monday Pickle delivery number one arrives
- Tuesday Pickle deliveries two through nine arrive
- Wednesday IT Security disconnects the fridge
## 3. Root Cause

The smart fridge was connected to the main Inator Network with its default password.

## 4. Corrective Actions

**4.1 Smart Device Rule.** Smart devices now live on an isolated subnet, see Acceptable Use of Inator Network Policy 2.0.

**4.2 Pickle Budget.** No pickle budget was approved.

## 5. Sign-Off

Reviewed by the Incident Commander and filed with Incident Response. A joke was included in the cover email, per HR Policy.
