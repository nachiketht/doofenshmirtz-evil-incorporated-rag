## Token Economy FAQ — Version 1.0

## 1. About This FAQ

Answers to the questions employees ask most about Focus Tokens under the Time & Usage Policy.

## 2. Earning Tokens

**2.1 Base Allocation.** Q: How many tokens do I get? A: Under Time & Usage Policy 3.0 you get 750,000 tokens per six-hour cycle.

**2.2 Foosball Bonus.** Q: Do I still win tokens at foosball? A: Yes, but only a flat 10,000-token bonus. You no longer take the loser's tokens.

## 3. Spending Tokens

**3.1 Gifting Tokens.** Q: Can I give tokens to a friend? A: No. Gifting, pooling and borrowing tokens are still prohibited, and losing at foosball on purpose is detected by the monitoring AI.

**3.2 Running Out.** Q: What happens if I run out? A: Ask the Chief Token Officer, and if he says no, enjoy some skincare.
